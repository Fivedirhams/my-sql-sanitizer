# Address masking template - Language & Country aware

Replace '{original_address}' with a realistic address in the same country.
Keep the general format (street number, street name, city).
Return ONLY the new address.

Country examples:
- Spain → "Calle Velázquez 45, Madrid, Spain"
- Brazil → "Rua Augusta 789, São Paulo, Brasil"
- USA → "123 Main Street, New York, NY 10001, USA"
- Russia → "ул. Тверская 15, Москва, Россия"
- France → "15 Rue de Rivoli, Paris, France"

Important: Do NOT change the script/language! Spanish stays Spanish, Russian stays Russian.
